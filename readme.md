# Multi-Agent Detection of AI-Generated (Deepfake) Speech

Multi-Agent Detection of AI-Generated (Deepfake) Speech
Problem explanation
Detect AI-generated speech using multiple specialized agents (spectral, prosodic,
linguistic) whose outputs are fused by a decision agent.
Dataset (2024–2025)
• ASVspoof 2024 & 2025 Logical Access corpora
Key limitation
• Single detectors overfit to known generators
New research contribution
• Multi-agent voting + explanation
• Robustness to unseen generators
